# Contribuer

Les retours de jeu sont essentiels pour améliorer la VF.

## Signaler une traduction

Ouvrez une issue et indiquez :

- le chapitre et la scène ou route ;
- le personnage qui parle et le contexte ;
- la phrase affichée ;
- votre proposition, si vous en avez une ;
- une capture d'écran, si possible.

## Terminologie

Les termes principaux suivent autant que possible la VF de l'anime :

| Anglais | Français retenu |
|---|---|
| Upa / Metal Upa | Oopa / Oopa en métal |
| Luka / Lukako | Ruka / Rukako |
| World line | ligne d'univers |
| Attractor Field | Champ Attracteur |
| D-mail | D-mail |
| PhoneWave | téléphone micro-ondes |
| Future Gadget Laboratory | Laboratoire des gadgets futuristes |
| Lab Member | membre du labo |
| El Psy Kongroo | El Psy Congroo |

Un changement global de terminologie doit être discuté avant une pull request.

## Pull requests

Les PR sont bienvenues pour la documentation et l'installeur. Les sources de travail du
scénario ne sont pas publiées dans ce dépôt; pour une correction textuelle, commencez par
une issue afin qu'elle soit intégrée puis recompilée dans les deux archives.

Ne joignez aucun fichier original non modifié du jeu ni capture contenant un spoil non signalé.
Les corrections apportées aux fichiers ASS de `sources/video` sont les bienvenues.
