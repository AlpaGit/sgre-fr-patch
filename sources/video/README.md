# Sources des sous-titres vidéo

Les trois fichiers ASS correspondent aux vidéos chiffrées `prologue01_en.webm`,
`prologue02_en.webm` et `prologue03_en.webm` de STEINS;GATE RE:BOOT.

Leurs timings suivent l'apparition et la disparition du texte anglais incrusté. Les vidéos
rendues ne sont pas suivies dans l'historique Git en raison de leur taille ; elles sont fournies
uniquement dans l'archive binaire de la release.
